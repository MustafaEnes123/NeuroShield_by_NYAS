            Security

            • On-device encryption. EEG is encrypted with AES-256 before it leaves the headset.
            • TLS 1.3 transport. Streams go through Azure API Management into Azure Event Hub.
            • Signed commands. The headset's hardware security module verifies every stimulation command and resets on a signature mismatch.
            • HIPAA-aligned access. Only people on your care team can open your records.
